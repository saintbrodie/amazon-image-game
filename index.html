About the game

What Did They Buy?

Guess products from customer review photos. The daily challenge selects the same five rounds and answer order for everyone using the same dataset and UTC date.

The bundled demo uses original mock images. The data tools can turn image-bearing Amazon Reviews 2023 records into game rounds without live-scraping Amazon.

This project is not affiliated with or endorsed by Amazon. Review images and metadata from third-party datasets may have separate rights and usage restrictions. Check those terms before publishing a dataset-backed deployment.
